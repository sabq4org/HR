# سبق — مساحة الفريق

تطبيق شؤون موظفين عربي RTL، بإصدار معاينة وظيفية **0.2.0**. يجمع ملف الموظف، الخدمات والموافقات، المستندات الخاصة، الإجازات والحضور، ومسيرات رواتب اصطناعية في تطبيق واحد. جميع الأشخاص والأرصدة والسياسات بيانات تجريبية؛ لم يُعتمد لاستقبال بيانات موظفين حقيقية أو تنفيذ استحقاقات نظامية.

[المعاينة العامة](https://hr-production-90b34ef5.up.railway.app) · [حالة التنفيذ والقبول](STATE.md) · [دليل التجربة](docs/demo-guide.md) · [تغطية الحزمة المصدرية](docs/administrative-scope.md)

يتضمن هذا الفرع أيضًا وحدة فوترة للنسخة الخاصة، قيد التطوير ولم تُنشر: العملاء، عروض الأسعار بهوية سبق، التحويل إلى مسودة فاتورة، وإعداد ربط وافق. [دليل الفوترة](docs/private-finance.md) · [تقرير الدفعة وحدود القبول](docs/releases/2026-11-14-private-finance.md) · [عقد واجهة وافق](docs/wafeq-api-contract.md). اكتمال المرحلة الثانية واسترجاع QR/XML الرسميين ما زالا ينتظران تأكيد المزود؛ نجاح البناء أو حفظ المفتاح لا يثبت الاعتماد الضريبي.

## التشغيل المحلي

Node.js 24.13 أو أحدث وnpm:

```sh
npm ci
npm run dev
```

افتح http://127.0.0.1:4317 . تُنشأ SQLite في `.data/hr-local.sqlite` ومفتاح تشفير محلي بصلاحية 600 في `.data/hr-data.key`. احتفظ بالمفتاح مع النسخ الاحتياطية؛ فقده يمنع قراءة الحقول والمستندات المشفرة. البيانات تبقى بعد إعادة التشغيل؛ جلسة الدخول مؤقتة.

لدعم PostgreSQL في قاعدة HR مخصصة: اضبط `HR_DB_DRIVER=postgres` و`DATABASE_URL` و`HR_DATA_KEY` من إعدادات آمنة وفق `.env.example`. يستخدم الوضع المحلي مخطط `hr_development`. لا تطبع رابط الاتصال أو المفتاح ولا تضفهما إلى Git. يمكن استخدام SQLite بدون أي خدمة سحابية.

## ما يمكن تجربته

- ملف موظف من 54 حقلًا، إنشاء وتعديل مسبب، تاريخ تغييرات وفترات عمل، وثائق وطلبات مرتبطة، واستيراد XLSX بمعاينة ثم حفظ ذري.
- 19 نموذج خدمة إدارية، إلى جانب مسار الإجازة السنوية: عقود وتقييم تجربة، خطابات، تحديث بيانات وبنك ونقل، إجازات خاصة وتسويات رصيد، إضافي ومكافآت وسلف، إخلاء طرف وإنهاء وتسوية وجزاء وتظلم.
- مسودة، إرسال، إرجاع للتعديل، إعادة إرسال، رفض مسبب، إلغاء المعلّق واعتماد مستقل. لكل نوع مسار محفوظ وصلاحيات خادمية.
- خطابات عمل وراتب وخبرة تُحفظ لقطةً مشفرة وقت الاعتماد، مع طباعة وحفظ PDF من المتصفح. تعديل الملف لاحقًا لا يغيّر الخطاب الصادر.
- مستندات PDF/PNG/JPEG خاصة ومشفرة، تنزيل مصرح، أرشفة، تواريخ انتهاء وملخصات فعلية.
- حضور يدوي ومراجعته، تقارير وتصدير CSV، سجل تدقيق، وسجل سياسات بإصدارات ومصدر وتاريخ سريان.
- مسير شهري مشتق من مكونات الأجر في الملفات الاصطناعية، إضافي ومكافآت معتمدة، مراجعة مالية ثم اعتماد وقفل، قسائم شخصية، مسير فروقات مرتبط، وتسجيل حالة دفع يدوي دون تحويل أموال.

ست شخصيات تمثل الموظف والمدير والموارد البشرية والمالية والمعتمد والمراجع. تفاصيل رحلة الأدوار في [دليل التجربة](docs/demo-guide.md). العناوين بخط **The Year of Handicrafts** ومدات انتقائية، والنماذج والجداول بخط **IBM Plex Sans Arabic**؛ الشعار أبيض على واجهة الدخول الزرقاء. الخطوط والشعارات محلية.

## التحقق

```sh
npm run format:check
npm run typecheck
npm test
npm run build
npx playwright install chromium webkit
npm run test:e2e
npm run test:finance
npm run test:recovery
```

اختبارات المتصفح تستخدم قاعدة مؤقتة مستقلة على المنفذ 4318. للتأكد من المعاينة العامة المأذون بها: `HR_TEST_HOSTED=true npm run test:e2e`؛ النطاق مثبت ولا يقبل وجهة إنتاج أخرى. `HR_TEST_DATABASE_URL` يشغّل اختبار PostgreSQL المعزول؛ وتشغيل `HR_ACCEPTANCE_POSTGRES=true node --import tsx --test tests/domain/workflows-acceptance.test.ts` يختبر مسارات الخدمات على PostgreSQL. الاستعادة تختبر SQLite دائمًا وPostgreSQL إذا توفر اتصال اختبار **محلي** وأدوات pg_dump/pg_restore. النتائج المنفذة فعلًا في [STATE.md](STATE.md).

GitHub Actions يشغّل التنسيق والأنواع والاختبارات والبناء والمتصفحين مع PostgreSQL 17 تجريبيًا عند الدفع إلى `main` وعند فتح PR. اختبار المالية مستقل ببيانات اصطناعية ومزود وهمي على المنفذ 4319، ولا يتصل بوافق.

## الاستضافة والحفظ

المعاينة العامة الحالية بمساحة وهمية مستقلة لكل زائر وSQLite في الذاكرة. تبديل الشخصية يحافظ على مساحة الزائر. تنتهي بعد ساعتين من الخمول أو ثماني ساعات من الإنشاء أو إعادة تشغيل الخدمة. حدها 50 مساحة، 250 عملية تغيير لكل مساحة، 200 موظف و30 مستندًا ومجموع مستندات 6 MiB (المؤرشف محسوب). المستند الواحد 2 MiB. هذه حدود معاينة صغيرة بعملية خادم واحدة.

إعداد Railway: بناء `npm run build`، وبدء `HR_MODE=hosted-demo HR_PUBLIC_ORIGIN=https://hr-production-90b34ef5.up.railway.app npm start`، وفحص `/api/health`. القيم المرجعية في `docs/railway-preview-settings.json`. النشر التلقائي من `main`، وإثبات نجاح النشر مستقل عن رفع Git.

لم تُربط Neon؛ المستخدم أنشأ قاعدة مخصصة ولم يذكر اسم مشروعها بعد. دعم PostgreSQL مختبر محليًا. خيار مخطط مؤقت لكل زائر موجود، لكن لا يُفعّل طويلًا قبل إضافة تنظيف المخططات المتبقية بعد انقطاع العملية وإعداد المفاتيح الدائمة.

```sh
npm run db:backup
npm run db:verify -- .data/backups/اسم-النسخة.sqlite
```

تفاصيل الترحيل وحفظ المفتاح والتراجع في [دليل الخادم](server/README.md).

## حدود التشغيل الواقعي

هوية التجربة ليست SSO/MFA. يلزم اعتماد الهيكل ومصفوفة الصلاحيات والبدلاء وسياسة الاحتفاظ والاستضافة قبل بيانات حقيقية. السياسة السنوية 24 يومًا والأحد–الخميس اصطناعية. لا نسب تأمينات أو حاسبة نهاية خدمة نظامية مثبتة؛ التسويات قيم يدوية للمراجعة. لا تحويل مصرفي أو تكامل حكومي أو توقيع قانوني أو إرسال بريد/SMS. لا جدولة تلقائية لتغييرات الموظف المستقبلية؛ يمكن إعداد الطلب، ويُرفض اعتماده المؤثر قبل تاريخ السريان. تفاصيل ما نفذ وما بقي في [تقرير الإصدار](docs/releases/2026-11-14-functional-preview.md).
