# قرار 009 — الفوترة الخاصة ووافق

التاريخ: 14 نوفمبر 2026.

## الطلب والقرار

طلب المالك إنشاء العميل وعرض السعر والفاتورة داخل HR، والاحتفاظ بنسخ محلية بتصميم سبق، مع مزامنة العميل والفاتورة مع وافق. القسم مخصص لحساب موظف محدد داخل النسخة الخاصة.

نضيف الوحدة إلى تطبيق Express وReact وقاعدة البيانات الحالية، دون خدمة جديدة أو اعتماديات جديدة. مفتاح `HR_FINANCE_EMPLOYEE_ID` يحدد حسابًا واحدًا؛ لا توجد صلاحية تلقائية لكل مستخدمي الموارد البشرية أو المالية. يظهر رابط «النظام المالي» في القائمة بناءً على صلاحية يعيدها الخادم، وتعيد كل نقطة API التحقق من الحساب ومالك المورد. لا تتاح الوحدة في المعاينة العامة.

## ملكية البيانات والإصدار

- العميل يُنشأ أولًا في HR، ثم يُربط بمعرّف وافق. تحفظ بياناته مشفرة. بعد بدء المزامنة تُقفل بياناته إلى حين حسم نتيجة المزود؛ لا يوجد تحديث عميل متزامن في هذه الدفعة.
- عرض السعر يحمل نسخة مستقلة من العميل والبائع والبنود والأرقام. طباعة العرض بتصميم سبق ولا تتضمن QR.
- بيانات الحساب البنكي اختيارية للعرض فقط، وتدخل ضمن نسخة البائع المشفرة. لا يضيف هذا الحقل خدمة دفع أو تحويلًا ماليًا ولا يغيّر حمولة وافق.
- التحويل يحجز رقمًا ثابتًا `HR-INV-…` وينشئ مسودة واحدة مرتبطة بالعرض. الرقم المحجوز وحده لا يعني إصدارًا ضريبيًا.
- الأرقام محفوظة بالهللات، وحساب الكميات والضريبة يستخدم كسورًا عشرية محددة الدقة. البنود لا تُستبدل بعد التحويل.
- العملية الخارجية تحفظ مفتاحي UUID ثابتين للإنشاء والإبلاغ، ومعرّف المورد المحلي. انقطاع الاتصال ينتج حالة تحتاج مصالحة، ولا يعني الرفض أو القبول.
- نستخدم Wafeq Accounting Public API ثم عملية الإبلاغ الخاصة بالفاتورة نفسها. لا نكرر إنشاءها في واجهة ZATCA المستقلة.

## الأسرار والمخرجات

المفتاح يدخل مرة واحدة في «النظام المالي ← إعدادات وافق». يتحقق الخادم من منشأة المفتاح ويحفظه بـAES-256-GCM مع `HR_DATA_KEY` الحالي. لا يعود المفتاح في API ولا يُحفظ في المتصفح أو Git أو تفاصيل التدقيق. لا يقبل استبدال المفتاح بمفتاح منشأة مختلفة.

حالة المحاسبة لدى وافق ليست إثبات اعتماد من الهيئة. المخطط المنشور لا يحدد حقل QR/XML أو جميع قيم نتيجة الهيئة النهائية. لذلك يحجب المحول الحالات غير الموثقة، ولا يولد باركودًا من بيانات المسودة. طباعة فاتورة نهائية بتصميم سبق تنتظر دليل قبول ومستند تحقق صالحين. الفاتورة المبسطة غير مفعلة في هذه الدفعة حتى يكتمل عقدها المحاسبي والضريبي.

هذه إضافة للتطوير والاختبار المحلي وليست إقرارًا باكتمال المرحلة الثانية أو نشرًا على الخدمة الخاصة. تفاصيل الإعداد والحدود والتحقق في [دليل الفوترة الخاصة](../private-finance.md) و[عقد وافق](../wafeq-api-contract.md).
