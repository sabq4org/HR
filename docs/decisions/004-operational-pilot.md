# 004 — دفعة الحسابات والملف الوظيفي والإجازات

التاريخ: 14 نوفمبر 2026. اعتمد المستخدم تنفيذ توصية دفعة تشغيل الملف الوظيفي والإجازات لمجموعة محدودة، واختار حسابات داخل النظام مع تحقق بخطوتين.

## الهدف والنطاق

حسابات موظفين دائمة مع كلمات مرور وتحقق TOTP إلزامي، تفعيل محدود العمر واستعادة وإلغاء جلسات؛ بيئة دائمة مستقلة عن المعاينة العامة؛ سياسات إجازة مؤرخة ومعتمدة وربطها بالموظف؛ طلبات تعديل وإلغاء الإجازة المعتمدة وتمديدها والعودة المبكرة؛ تنبيهات داخلية مجدولة ودليل استعادة.

تبقى التجربة ببيانات اصطناعية. اعتماد التنفيذ البرمجي لا يحدد هوية أصحاب الصلاحية أو الأرصدة أو السياسة النظامية، ولا ينقل بيانات الموظفين أو يفعّل حسابًا باسم شخص حقيقي. لا يُغيّر نشر المعاينة القائمة أو تُنشأ خدمة مدفوعة في هذه الدفعة. الرواتب النظامية والتسوية والتوقيع والتكامل الحكومي وإرسال الرسائل الخارجية تحتاج دفعاتها المعتمدة.

## التقنية والعقود

يبقى تطبيق React/Express وقاعدتا SQLite/PostgreSQL. يضاف `otplib` بإصدار مثبت لتوليد وفحص TOTP بدل كتابة خوارزمية المصادقة. تستخدم كلمات المرور scrypt غير المتزامن من Node، وتخزن الجلسات والرموز كتجزئات، وأسرار TOTP بالتشفير الحالي مع سياق مرتبط بالسجل. توثيق المكتبة: https://otplib.yeojz.dev/api/otplib/ .

الترحيل 013 للحسابات، 014 للإجازات والسياسات، 015 للمهام والتنبيهات. التنفيذ إضافي؛ لا تعدّل الترحيلات السابقة أو أرصدة ومسيرات مغلقة. التراجع بإعادة إصدار متوافق على نسخة منفصلة بعد نسخة احتياطية موثقة، ولا يُحذف أثر البيانات لإجبار التراجع.

واجهة `/api/auth/*` مستقلة عن شخصيات العرض. وضع الحسابات يعطل دخول العرض تمامًا. تظل كل الصلاحيات خادمية وعلى المورد. سياسة غير معتمدة تمنع احتساب الإجازة المعنية دون منع المستخدم من فتح ملفه. تعديل إجازة معتمدة يحتاج طلبًا مستقلًا وقرارًا مؤرخًا وحركات مقابلة، مع منع التكرار والتعارض داخل معاملة واحدة.

## القبول

اختبارات حسابات: لا وصول قبل التفعيل والتحقق، منع إعادة رمز التحقق/التفعيل/الاستعادة، تحديد المحاولات، إلغاء الجلسات بعد التعطيل وإعادة التعيين، عدم كشف بيانات حساب آخر. اختبارات إجازة: صلاحيات واعتماد مستقل، تداخل وتزامن، إعادة إرسال، ثبات السياسة والحساب التاريخي وعكس الرصيد مرة واحدة. اختبارات تشغيل: حفظ بعد إعادة التشغيل، فصل المعاينة، إعادة تنفيذ التنبيهات دون تكرار، استعادة محتوى ومفاتيح وجداول الحسابات. قبول متصفح بالعربية والجوال، ومراجعة مستقلة قبل التسليم.

بوابة الاستخدام الفعلي: اختيار استضافة وقاعدة HR مخصصتين، حفظ المفتاح الدائم، تحديد مسؤولي الحسابات والمعتمدين، اعتماد السياسة والأرصدة والتقويم والاحتفاظ، ثم تجربة HR على عينة. لا تعني نتائج الاختبارات وحدها قبول الإنتاج.
