# 001 — الأساس المحلي وتجربة الصفحات الأولى

التاريخ: 2026-11-13. الحالة: قرار هندسي للتجربة المحلية، لا اعتماد استضافة أو سياسة عمل.

## النطاق
تطبيق محلي واحد: لوحة رئيسية، دليل موظفين حسب الصلاحية، ملف وظيفي، طلبات إجازة، صندوق موافقات، وتقويم فريق. بيانات اصطناعية فقط. مسار إرسال إجازة ثم مدير ثم HR، مع إلغاء الطلب المعلّق. الرواتب، رفع الملفات، الاستيراد، التكاملات والعودة المبكرة خارج هذه الدفعة.

## التقنية قبل إضافة الاعتماديات
- React + TypeScript وVite لبناء واجهة تفاعلية ذات أنواع مشتركة مع الخادم.
- Express في عملية واحدة يخدم API وواجهة Vite أثناء التطوير والملفات المبنية عند المعاينة.
- SQLite عبر node:sqlite محليًا: قاعدة علائقية ومعاملات فعلية دون حساب خدمة أو Docker. يلزم Node 24.13 أو أحدث. الانتقال إلى PostgreSQL للإنتاج قرار مستقل يتطلب إعادة التحقق من التزامن والترحيل؛ ليست هذه موافقة إنتاج.
- CSS مخصص ومكونات صغيرة، lucide-react للأيقونات، وخط IBM Plex Sans Arabic مستضاف محليًا عبر حزمة npm. لا طلبات خط أو صور لطرف ثالث عند استخدام التطبيق.
- اختبارات node:test للخدمات، Playwright وaxe للرحلة والمتصفح وإتاحة الوصول.

وثائق التقنية المرجعية: https://vite.dev/guide/ ، https://expressjs.com/en/5x/api/express/ ، https://nodejs.org/api/sqlite.html . الإصدارات الفعلية تثبت في package-lock.json.

## تجربة وهوية
اسم المساحة: «سبق — مساحة الفريق». التوجّه: هدوء لوحة عمل محترفة مع شخصية عربية مرتبطة بفريق تحرير، لا نسخة من بوابة حكومية ولا لوحة مؤشرات مزدحمة.

الألوان: حبر #142D48، أزرق سبق #1264A3، أزرق فاتح #EAF3FA، أرضية #F5F7FA، أبيض #FFFFFF، أخضر حالة #23806A. خط واحد عربي متغير؛ الأرقام لاتينية، التواريخ عربية مع توقيت الرياض.

التخطيط: تنقل رأسي ثابت يمينًا، رأس رشيق، تحية ومساحة تركيز أفقية، ملخصات قليلة، ثم طلبات وتغطية الفريق. يتحول التنقل لقائمة جوال. محاذاة عربية يمينًا. مساحة التركيز هي العنصر البصري المميز؛ بقية العناصر هادئة وبلا زخرفة زائدة.

```
|                شريط البحث والحساب             | سبق |
|     التاريخ         عنوان الصفحة              | تنقل |
| رصيد الإجازة |    التحية والإجراء التالي         |      |
|              ملخص العمل                       |      |
| تقويم الفريق |        الطلبات                 |      |
```

مراجعة التوجه: استُبعدت البطاقات المتساوية المتكررة والتدرجات الزخرفية. الرصيد والموافقات يعرضان بيانات فعلية من الخادم، والإجراء الرئيسي يفتح طلبًا قابلًا للحفظ. لا أزرار شكلية أو ادعاءات قانونية. تمييز التجربة الاصطناعية واضح دون حشو تقني داخل المسارات.

## عقد التنفيذ والقبول
`shared/contracts.ts` يملك العقد المشترك. الخادم مسؤول عن الهوية التجريبية المقيدة بالمضيف المحلي، صلاحية المورد، رقم النسخة، مفتاح منع التكرار، والمعاملة الذرية للحجز/القرار/التدقيق. لا تُقرأ الهوية من قيمة موظف يرسلها العميل عند إنشاء الطلب. الموظف يرى نفسه، والمدير فريقه، وHR النطاق التجريبي كله.

معيار القبول: بناء وفحص أنواع ناجحان؛ اختبار 401/403؛ رفض اعتماد الذات؛ إرسال مكرر يحجز مرة واحدة؛ منع التداخل ونفاد الرصيد؛ مراجعة مدير ثم HR؛ إلغاء طلب معلق يعكس الحجز؛ عرض عربي يعمل على الهاتف ولوحة المفاتيح. توثيق ما لم ينفذ في STATE.md.

الحدود الأصلية قبل إرسال المستودع: لا تهيئة Git ولا إنشاء مستودع خارجي، ولا نشر أو إرسال بريد حقيقي.

تحديث النطاق أثناء التنفيذ: أرسل المستخدم المستودع https://github.com/sabq4org/HR.git؛ فُحص وكان فارغًا، ثم هُيئ Git محليًا وربط `origin` به على الفرع `codex/hr-foundation`. في 14 نوفمبر 2026 طلب المستخدم رفع العمل إلى GitHub صراحة، فأنشئ الفرع الرئيسي `main` ورُفعت دفعة التأسيس إليه. لم يُنشر تطبيق أو تنشأ استضافة.

تحديث الهوية: استخدمنا خط The Year of Handicrafts الذي قدمه المستخدم للعناوين الكبيرة والترحيب، مع مدات خفيفة. بقي IBM Plex Sans Arabic للنصوص والجداول. أضيف الشعار والعلامة المختصرة من ملفات SVG الأصلية التي قدمها المستخدم، دون تعديل نسبها أو ألوانها.
