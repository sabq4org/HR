# استكمال بيانات الملفات المستوردة

الأداة المحلية `npm run private:supplement` تملأ الحقول الاختيارية الناقصة من تصدير الموظفين. لا تنشئ موظفين، ولا تستبدل القيم الموجودة، ولا تمنح أدوارًا، ولا تعدل رصيد الإجازة. إعداد قاعدة البيانات والمفتاح مطابقان لأدوات الإدارة الخاصة في `docs/private-local.md`.

## بيان الربط

يحفظ خارج المستودع، ويُراجع قبل التطبيق. يثبت بصمة الملف كاملة ورقم الصف ومعرف الموظف الداخلي ونسخة السجل المتوقعة. لا تعيد أداة التطبيق مطابقة الأسماء أو البريد؛ سجلات المصدر التي لا توجد في البيان تُتخطى.

```json
{
  "version": 1,
  "sourceSha256": "بصمة SHA-256 للملف، 64 حرفًا ست عشريًا",
  "rows": [{ "rowNumber": 2, "employeeId": "معرف داخلي مراجع", "expectedRecordVersion": 1 }]
}
```

## المعاينة ثم التطبيق

```bash
npm run private:supplement -- /مسار/الموظفون.xlsx --manifest /مسار/ربط-خاص.json --dry-run
npm run private:supplement -- /مسار/الموظفون.xlsx --manifest /مسار/ربط-خاص.json --apply
```

المعاينة هي الافتراضية عند حذف `--dry-run`. احفظ نسخة احتياطية خاصة، ثم راجع `eligibleRows` و`invalidPatches` و`conflicts` و`staleRows` قبل التطبيق. تعرض النتائج أعدادًا ورموز أخطاء فقط. لا ترفع ملف الموظفين أو بيان الربط أو النسخة الاحتياطية إلى Git.

## السلوك المتوقع

- يوقف عدم تطابق بصمة الملف بيان الربط؛ وتمنع النسخة المتغيرة تحديث السجل المعني.
- القيمة الصفرية الصريحة محفوظة، بينما الخانة الفارغة تبقى غير مسجلة.
- القيم القائمة المتعارضة لا تُستبدل. إعادة التطبيق لا تكرر التعديل الذي سجل أثره سابقًا.
- لا تُختلق تواريخ سريان أو تحقق. البيانات المنقولة ومصدرها تحتاج المراجعة المناسبة قبل الاعتماد.
- نوع العلاقة منفصل عن التسجيل بالتأمينات. الاستحقاق السنوي المدوّن منفصل عن الرصيد الافتتاحي المعتمد.
- الرصيد الافتتاحي يمر بطلب تعديل رصيد من نوع «رصيد افتتاحي»، مع المصدر وتاريخ السريان واعتماد مستقل؛ لا ينشئ الاستيراد هذا القيد.
- تعديل الحساب البنكي يستدعي تحققًا يدويًا جديدًا، ولو كان موثقًا سابقًا.

تصدير الموظفين الذي راجعناه لا يحتوي مكونات الرواتب؛ قرر المالك إدخالها لاحقًا. يبقى كشف المستحقات المالي الموحد مؤجلًا.
