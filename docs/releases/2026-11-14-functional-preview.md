# تقرير تسليم المعاينة الوظيفية — سبق HR 0.2.0

التاريخ: 14 نوفمبر 2026. المرجع المحلي: `/Users/alialhazmi/HR`، والمستودع: https://github.com/sabq4org/HR . الرابط العام المخصص: https://hr-production-90b34ef5.up.railway.app . هذا تقرير تنفيذ قابل للتحقق، لا اعتماد تشغيل موارد بشرية ببيانات حقيقية.

## النتيجة

توسّعت دفعة الصفحات الأولى إلى تطبيق واحد بواجهة عربية وخادم وقاعدة علائقية، فيه ملفات موظفين قابلة للتعديل، نماذج محفوظة ومسارات موافقة، مستندات خاصة، استيراد Excel، خطابات محفوظة وقت إصدارها، حضور ومسيرات تجريبية وتقارير وتدقيق. حُفظ تصميم سبق وخط العناوين The Year of Handicrafts وخط IBM للنصوص والشعار الأبيض على صفحة الدخول.

اختار المالك استمرار المعاينة العامة بشخصيات وهمية ومساحة مستقلة لكل زائر. لم نُنشئ خدمة مدفوعة أو قاعدة سحابية أخرى، ولم نستورد بيانات موظفين فعلية. أفاد بأنه أنشأ قاعدة Neon مخصصة وسيذكر اسم مشروعها؛ الربط السحابي ينتظر الاسم. دعم PostgreSQL نُفذ واختُبر فعليًا في بيئة محلية منفصلة.

## التحقق المنفذ

- فحص الأنواع والبناء ناجحان. فحص الاعتماديات الإنتاجية `npm audit --omit=dev --audit-level=moderate` أعاد صفر ثغرات معلنة وقت التشغيل.
- اختبارات المجال وAPI تغطي الأدوار الستة ونطاق المورد ومنع الاعتماد الذاتي، إعادة المحاولة والكتابة المتعارضة، ترحيلات وإعادة فتح البيانات، الصيغ والاستيراد الذري، صلاحيات الوثائق، مصدر المكافآت، قفل الرواتب والتصحيح والدفع، تواريخ سريان المستقبل، وثبات الخطاب بعد تعديل الملف وحجب الملاحظة الطبية.
- `HR_ACCEPTANCE_POSTGRES=true node --import tsx --test tests/domain/workflows-acceptance.test.ts`: **23/23** على PostgreSQL محلي مستقل.
- `npm run test:recovery`: نجحت استعادة SQLite وإعادة فك حقول الموظف والمستند الخاص، ونجح pg_dump/pg_restore إلى قاعدة محلية معزولة مع مطابقة الحقول والمرفق المشفر.
- مراجعة مستقلة للاستيراد والصلاحيات والمستندات الصادرة والترحيل والاستعادة؛ عولجت الملاحظات المؤثرة. فحص بصري للملف والخطابات والخدمات، مع إصلاح تبويبات الملف ومسار الطلب المنتهي وتباين نصوص الاستيراد.
- التحقق المجمع النهائي: `npm test` **66/66** دون تخطي، و`npm run test:e2e` **24/24** على Chromium وWebKit تشمل الإنشاء والاستيراد والموافقات والخطابات والرواتب وطباعة المستندين والجوال 390/320 بكسل والإتاحة الآلية. التنسيق والأنواع والبناء ناجحة. حالة CI والنشر مثبتة أدناه.

حدود الدليل: متصفحات Chromium وWebKit وأحجام عرض محاكاة؛ لا هاتف فعلي ولا قارئ شاشة بشري أو اختبار حمل واسع. axe فحص آلي لا شهادة إتاحة. الاستعادة محلية وليست تمرين تعافي على استضافة إنتاجية. لم تُراجع أحكام الحزمة قانونيًا ولم تتحول الأمثلة إلى سياسة شركة.

## الملفات والأوامر

الواجهة: `src/administration/`, `src/imports/`, `src/letters/`, `src/payroll/` مع دمج التنقل والملف والإشعارات في الملفات الأصلية. الخادم: `server/administration/`, `server/imports/`, `server/letters/`, `server/payroll/`, `server/database.ts` و`server/hosted-demo.ts`. العقود المشتركة: `shared/administration.ts`, `shared/catalog.ts`, `shared/imports.ts`. البيانات: ترحيلات 004–007، ومجموعة PostgreSQL 001–007. الاختبارات: `tests/domain/` و`tests/e2e/`. التشغيل: `scripts/database-operations.ts`, `scripts/verify-recovery.ts`, `.github/workflows/ci.yml`.

الأوامر الرئيسية: `npm run format:check`, `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`, `npm run test:recovery`, `npm run db:backup`, اختبار PostgreSQL أعلاه، و`HR_TEST_HOSTED=true npm run test:e2e` بعد النشر.

سجل النقل يحفظ الحقول السابقة والجديدة وتاريخ السريان والمعتمد، ويُمنع تعيين الموظف مديرًا لنفسه. تجديد العقد يحفظ تاريخ العقد داخل فترة الخدمة القائمة دون إنشاء فترة خدمة متداخلة؛ إعادة التوظيف وحدها تبدأ فترة جديدة بعد إغلاق السابقة. اختُبر ذلك على SQLite وPostgreSQL.

## الترحيل والتراجع

حُفظ إصدار السياسة المحلية القديمة ذات الراتب الثابت، وأضيف الإصدار 2 لاحتساب مكونات الملف في ترحيل 007؛ لا تُستبدل قيم سياسة معتمدة لتغيير طريقة الحساب. الخادم يرفض سياسة لا تطابق الحاسبة الاصطناعية.

أُخذت نسخة محلية قبل ترحيل 006، ثم فُتحت القاعدة وتحقق تسجيل الإصدارات السبعة دون تصفير بياناتها. إن وُجدت في قاعدة تطوير قديمة مسيرات أساسية مكررة للفترة نفسها، فقد يرفض الفهرس الفريد الترحيل؛ يفحص التشغيل ذلك وتُراجع التعارضات قبل التحديث دون حذف سجل مغلق. تفاصيل الاستعلام في `server/README.md`.

المعاينة العامة تستخدم قواعد جديدة مؤقتة لكل مساحة؛ تحديث النشر يعيد التجارب ولا يرحل بيانات موظفين حقيقية. التراجع العام إلى إصدار Git السابق يعيد التطبيق السابق مع مساحات جديدة. للتراجع المحلي استعد قاعدة ومفتاحًا متطابقين من نسخة متحققة بعد إيقاف الخادم، دون ملفات WAL قديمة؛ لا ترحيل هابط يمحو التاريخ.

## القرارات المفتوحة

1. اسم مشروع Neon المخصص، ثم الربط بإعدادات آمنة. لا حاجة لإرسال كلمة مرور في المحادثة. قبل تمكين مخططات PostgreSQL المؤقتة طويلًا يلزم تنظيف ما يبقى بعد انقطاع العملية.
2. اعتماد الدخول الحقيقي ومصفوفة الاعتماد والبدلاء والاستضافة والاحتفاظ قبل أي بيانات فعلية.
3. مراجعة السياسات المالية والنظامية مع المختص قبل التأمينات ونهاية الخدمة والجزاءات والتكاملات.
4. ظهرت سابقًا فاتورة Railway متأخرة؛ لم تُدفع ولم يتغير الاشتراك. نجاح النشر الحالي لا يحسم استمرار الخدمة من جهة الفوترة.
